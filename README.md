# ☀️ Solar Power Generation Prediction using Machine Learning

## Project Overview

This project predicts hourly solar power generation using weather parameters and a Random Forest Regression model.

The application is developed using Python and deployed using Streamlit Community Cloud.
Test Link
https://solar-power-prediction-mbsusoz2wptecgf2mkjafz.streamlit.app/
---
## Machine Learning Model

Algorithm:
- Random Forest Regressor

Performance:

- R² Score: 0.811
- MAE: 527.57
- RMSE: 804.16

---

## Input Features

The model uses the following weather parameters:

- Wind Speed (m/s)
- Sunshine (hours)
- Air Pressure (hPa)
- Solar Radiation (W/m²)
- Air Temperature (°C)
- Relative Air Humidity (%)
- Month
- Day
- Hour

## Output

Predicted Hourly Solar Power Generation
